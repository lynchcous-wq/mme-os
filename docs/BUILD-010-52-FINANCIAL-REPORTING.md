# Build 010.52 — Financial Reporting & Consolidation

## Existing source of truth preserved
Extends the existing Build 010.43 general ledger, chart of accounts, posted journal entries, trial balance, income statement, balance sheet and accounting-period close. No duplicate ledger or parallel journal engine was created.

## Added
- Reporting entity hierarchy for parent, subsidiary, store, department and elimination entities.
- Consolidation run register with period, currency, entity scope, eliminations and FX adjustment metadata.
- Intercompany elimination journal evidence structure.
- Immutable-by-version report snapshot records with source-system and source-watermark metadata.
- Budget-versus-actual variance records with generated variance amount.
- Financial close certification register with trial balance, unposted journal, unreconciled bank, AP and AR exception counts.
- Independent close certification RPC; submitter cannot certify own close.
- Expanded GL API and dashboard read panels.
- RLS and service-role-only access for all new reporting tables.

## Release boundaries
- Consolidation run and elimination tables are records only. No automated multi-entity ledger aggregation, intercompany balance detection/elimination, FX translation or minority interest computation.
- Financial snapshots are submitted payloads, not yet generated by a controlled report engine or immutable storage/signature service.
- Department/store profitability requires validated GL dimension mapping; current report data is not proof of complete POS, payroll, inventory COGS or cost allocation integration.
- Variance records are manually supplied; no automated budget engine integration in this build.
- Close certification checks balanced debit/credit totals, unposted journal count and unreconciled bank count. Open AP/AR counts are recorded but not automatically blocked or reconciled. Verify all source counts independently.
- The new certification function does not itself close the GL period. Use the existing GL close RPC only after review and certification.
- Service-role backend role mapping and organization/store-level scoping remain required production controls.
- No tax filing, audit opinion, GAAP/IFRS compliance certification or statutory reporting guarantee.
